# v1.7.7 — Armor Station fully refills Power Armor in <= 30 seconds

## Performance target
From fully empty/damaged to 100% of all three, concurrently, while standing
on one Armor Station for at most 600 server ticks (30 seconds at 20 TPS), **provided
there is enough real FE and NutriPaste input from connected source(s)**.

- **Power Armor energy:** four equipped pieces each have 4,000,000 FE baseline
  capacity (16,000,000 FE combined); station transfers up to **200,000 FE every
  five game ticks** from its original **200,000 FE capacity**. An external
  source must replenish the buffer; no FE is synthesized.
- **Structural integrity:** the existing repair rate is 10 HP per 5-tick
  service on each of the four items, 25 real FE per HP. From 0 to 1000 HP
  on each piece takes 100 services = **25 seconds**, provided repair FE is
  available. Priority over suit energy charging remains unchanged.
- **NutriPaste:** the helmet has **1,000,000 mB** capacity. A 500-mB station
  tank cannot meet the requested full-from-zero 30-second target, so station
  paste buffer is increased to **1,000,000 mB**. Existing stored paste is
  migrated intact; valid NutriPaste Fluid only; transactional input-only,
  persisted and exact debit on helmet refill.
- **Fluid cable throughput:** the normal default cable moves only 250 mB per
  5 ticks. When its destination is an **Armor Station**, transfer budget
  increases to at least **25,000 mB per five ticks** (40 transfers = 10 sec
  for one full helmet) while all non-Armor-Station destinations keep existing
  limits and upgrades. Real source fluid is still required. No cable tick
  frequency increase and no extra station ticker.

## Safety
- Never create FE or paste. Existing source/destination simulations and
  execute/refund behavior stay intact.
- Single player serviced per station cycle, no extra world scan.
- Station retains 200,000 FE capacity; NutriPaste buffer increases because
  previous 500 mB was fundamentally insufficient for full 1M-mB helmet.
- Existing J.A.R.V.I.S. status, armor integrity damage and 1.7.6 features
  unchanged.
- Dedicated code-shape tests, conservation tests and 30-second full-system
  simulation are included in CI.

## Requirement
Measured 30 seconds use normal **20 TPS**. If the connected FE or NutriPaste
sources provide less than the needed amount, or the server runs below 20 TPS,
wall-clock refill can take longer. This is not a creative/infinite refill.
