# 1.7.8 B1621: native terrain map / FTB-style claim GUI candidate

Base: verified green Build 1620, Git commit a4994e16aad65e36227bcfddf97f4eab2194175a.
This candidate must pass GitHub CI and real server tests before release.

## Original (not copied) FTB-style mouse operation
- Press M for full-screen interface. Click Map / Claims to switch modes.
- Claims mode: left-click or drag claim area; right-click or drag unclaim.
- Shift+left-click or drag *force-loads* owned claimed chunks; Shift+right-click or drag unloads.
- Server performs area operations in a bounded queue: at most 8 per player and 64 across the server per tick, no per-chunk commands, atomic persistent dirty-save batching.
- Ownership and force-loaded quotas remain separate. Existing server authorization and ticket controller unchanged.
- Terrain tiles sampled on client only if the chunk is *already* loaded: 4x4 Minecraft map-color sample/16x16 chunk, at most two samples/tick, cached 1536 chunks per dimension, no terrain scanning per frame.
- Minimap now draws terrain with chunk ownership borders and green forced-load stripe; map center follows current player on open, map mode pans with mouse drag, mouse wheel zooms.
- Native GUI Map/Claims/Center/Mini/Info buttons; C toggle mode, Space recenter, G toggle overlay, N minimap, H help, arrow keys pan.

## Parity status / known limits
This replaces the color-only claim grid from 1620. It covers the principal FTB input interactions and a genuine cached terrain map, but is **not full feature parity yet**: persistent cross-session explored-map storage, waypoints/deathpoints, complete FTB Teams semantics, biome/terrain detail resolution, all protection edge cases and server settings GUI still need implementation / in-game verification. Never represent it as identical to FTB Chunks.
