# xSxLabs Network Storage — v1.7.5 Animation Update

**Feature scope:** **Power Armor animation only**; do not mix in unrelated gameplay or network/storage changes.

## Agreed visual direction

- **Equip (normal):** the textured armor opens as a physical suit, player enters, the suit closes, with mechanical sequencing and a readable close-up.
- **Unequip (normal):** the armor opens, player exits, and the suit is set up as the already-existing freestanding world object; use the same high-quality opening/closing animation.
- **Recall:** keep the preexisting recall gameplay and controls. Armor flies **horizontally / lying down**, not upright, toward the player with visible jet/thruster effects; it aligns, opens and closes realistically around the player.
- **Back shell:** open **vertically in two halves along the rear centerline**, then close on equip. Use hinged actual full-texture model parts; avoid solid colored placeholder boxes.
- **Faceplate/helmet:** the faceplate moves from **above to the front** and reverses cleanly when opening; fully textured, with recognizable geometry.
- Use the flight/opening section of the **reference video provided by the user** as the animation-quality and sequencing guide.
- Movements must be smooth, cinematic, properly pivoted and synchronized. Preserve the armor's existing appearance in both equipped and world states.

## Functional preservation and performance

- No changes to FE consumption, armor stats, feeding, crafting, storage, cables, reactor, powerbank or solars unless expressly requested.
- Preserve existing player state, item ownership, recall permissions and multiplayer behavior.
- Animations are client-side where practical; no persistent 20 Hz world scans, unnecessary server load, excessive particle spawns or large FPS cost.
- Handle interruption safely (player disconnects, chunk unloaded, suit removed, interrupted recall), never duplicate armor or leave stuck entities.
- Maintain compatibility with the v1.7.4 frozen build.

4. First/third person, other players viewing, multiplayer, interruption and restart tested.
