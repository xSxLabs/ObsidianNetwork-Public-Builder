# 1.7.7 Attack Mode — longer manual bullet flight and double damage

- Manual fired bullets marked on the server after authorization.
- Previous: base **4 HP per hit**, lifetime **8 ticks** (about 24 blocks).
- New (manual Attack Mode only): **8 HP per hit**, lifetime **48 ticks** (typically over 100 blocks; collisions and drag still apply).
- Automatic turret/companion bullets retain base **4 HP** and **8 ticks**.
- Same physical projectile, collision checks, no damage through walls.
- Same 3,000 FE per shot, original fire cadence/attack module gates, client particles, and loot/safety.
- No additional per-tick search or infinite bullet lifetime.
