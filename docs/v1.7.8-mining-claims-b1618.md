# xSxLabs 1.7.8 — B1618 Chunk Claims + Mining Builder candidate

Green stable baseline: B1617 commit `2bbc5ecf797ad7806ee551d481990340e90f0673`. Version 1.7.7 remains unchanged. This is a **test candidate** until the CI build and server tests pass.

## Chunk system
- `M` opens the 25x25 full-screen **ownership grid**; a 7x7 top-right ownership minimap is also shown (no terrain map imagery yet).
- Left-click a chunk to claim/unclaim; right-click to load/unload; arrow keys pan.
- Commands: `/xsxchunks claim|unclaim|load|unload [chunkX chunkZ]`, `/xsxchunks view`, `/xsxchunks trust|untrust PLAYER` (player currently online).
- Own NeoForge chunk-loading ticket controller, does not override vanilla /forceload. Server limits: 256 owned / 25 loaded chunks per owner by default. Override on launch with `-Dxsxlabs.claims.max=256`, `-Dxsxlabs.claims.loaded=25`.
- Server-authoritative ownership checks for break/place/right-click; permission-based player trust. Not complete piston/fluid/explosion protection yet.
- Persistent world/data/xsxlabs-v178-claims.tsv, atomic dirty saves batched in available server idle ticks and server stop.
- Map requests: bounded 625 byte statuses; 1 request / 20 ticks / user, proximity-limit 256 chunks, no client terrain scans, no automatic chunk generation.

## Mining-only Builder
- Craft Mining Shape Card; right-click two blocks to set opposite corners, max 512 blocks/axis, 8,388,608 voxels.
- Craft Mining Builder; right-click with area card to install, shift-right-click to retrieve. Right-click with empty hand to read status.
- FE-only operation: 2,000 FE/block, 2,000,000 internal FE, 27-slot transactional item inventory with adjacent container output. No free mining energy or item duplication.
- Requires chunks in the area to have been claimed by the builder owner, pauses at unclaimed regions, unloaded chunks and full output.
- Skips bedrock, block entities, fluids; no construction/placing.
- Server tick caps: 8 voxels scanned + 2 blocks mined/machine/tick; 64 mined per dimension/tick globally (tunable: `-Dxsxlabs.mining.globalBreaks=64`).
