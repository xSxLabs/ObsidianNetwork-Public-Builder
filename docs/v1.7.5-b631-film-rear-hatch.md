# v1.7.5 B631 – film-style standing suit rear entry/exit

Context: After B629 green, the user confirmed that the Recall animation's
flight and assembly motion is correct, but animated shell textures must match
the actual worn MK armor. B630 imports exact worn equipment PNGs and maps
outer shell UVs. User also clarified normal entry/exit should be **from the
back**, rather than the front chest splitting.

B631 applies AFTER the B630 texture gate:
- Keep the real worn front torso exterior rigid in its original position.
- Normal enter/exit uses two existing rear shell doors rotating around the
  two OUTER vertical back-side hinge pivots with existing B629 keyframes.
- Keep the sole faceplate upper-hinged; no second baked visor cube.
- Move the three existing static torso interior wall/shelf cubes onto the
  already-established torso_inner_spine bone without changing any cube origin,
  size, texture or UV. When fully closed, original physical shell geometry is
  unchanged. During normal opening, scale away only that stationary inner
  carriage; restore its scale at the end of every normal clip.
- No unrelated loose motion of front chest, forearms, upper thighs or boots.
  Upper arms retain only subtle hinge movement.
- All recall_flight / recall_brake / recall_dock animation contents are
  asserted BYTE-for-BYTE equal in a pre/post deep JSON comparison. Runtime
  Java classes, FE, Cable Bundles, armor equipment and ownership untouched.
- Model remains exactly 28 bones for all MK1–MK24.
- A new independent 24-tier safety and original outer-UV test runs before
  the Java build.

Risk note: This corrects animated shell geometry and visual overlap, not the
owner's server-side physical movement/standing position. The standing suit's
world orientation is deliberately left intact so the already-approved recall
trajectory cannot be rotated accidentally. Full film-like body stepping
motion would require a separately verified player-motion change.

New in-game comparison should inspect from behind and both sides for seams,
mask hinge and any remaining intersecting surfaces.
