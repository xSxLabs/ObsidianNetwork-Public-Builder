# v1.7.7 — Inventory key E in xSxLabs GUIs with JEI

- While an active xSxLabs EditBox/MultiLineEditBox is focused: E must be entered as text, never close the screen.
- While the JEI search overlay has keyboard focus: E must be entered in JEI, never close the screen.
- With neither editor focused: E closes the xSxLabs screen, including GUIs without any text input.
- Only the active Inventory key binding is handled; ESC, other keys, vanilla and third-party screens keep their semantics.
- JEI remains optional: use the public IIngredientListOverlay.hasKeyboardFocus API from a separate @JeiPlugin runtime bridge, guarded by ModList.
- On JEI runtime teardown the bridge clears its reference; no reflection, no per-tick polling and no extra packets.
- CI tests check all cases, full NeoForge compilation and the distributable test JAR.
