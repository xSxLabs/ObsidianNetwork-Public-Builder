1.7.7 — Construction Wand / Building Gadgets server optimization

The existing B1307 ITEM capability continues consuming REAL items from the three Storage Cells in a Network Backpack. Construction Wands, Construction Sticks and Building Gadgets 2 still withdraw and spend blocks. Previously each capability query repeatedly decoded, merged and sorted all entries. This change caches only the read-only view, keyed by the full immutable ItemResource and its amount, using one item codec per view rebuild. Any transaction or source change invalidates it.

Actual extraction still calls V176BackpackCells.extract on a detached bag copy and ItemAccess.exchange in the same NeoForge transaction. No free blocks, ghost items or loss of persistence are introduced; abort/rollback must not spend any items. The placed Backpack, Cable and magnet handlers are not modified. Real server MSPT improvement still needs in-game measurement.
